🏠 Automação residencial com ESP32

Luzes e tomadas, 2 TVs, home theater e 2 ares-condicionados, pelo celular.

Demonstração · nada é enviado de verdade

Este é o mesmo painel que o ESP32 mostra no celular em http://casa.local, aqui simulado para você testar. O painel real vem embutido no firmware (webui.h).

Conectar ao broker MQTT e controlar de verdade

Precisa de internet. A senha fica guardada só neste navegador. O ESP32 precisa estar ligado e com o firmware atualizado.

⚠️ Segurança (127/220 V)
  • Os relés ficam entre a rede elétrica e a lâmpada. Desligue o disjuntor antes de mexer em qualquer fio.
  • Se você é iniciante, comece com o relé ligado a uma extensão ou tomada dentro de uma caixa fechada (ex.: um abajur), e não na parede.
  • Para ligar no interruptor ou no quadro, peça a um eletricista.
  • Mantenha a parte de 5 V separada da parte da rede, em caixa fechada e sem fio exposto.
  • Use relés de pelo menos 10 A / 250 V. Ar-condicionado grande não vai direto em relé de módulo: para isso use contator.

Qual LED atende o quê? A saída 0 atende TV sala, Home theater e Ar sala. A saída 1 atende TV quarto e Ar quarto. Aponte cada LED IR para os aparelhos do ambiente. Se os ambientes ficarem longe, leve o LED até lá com um cabo fino ou monte uma segunda placa com o mesmo firmware.

Tópicos MQTT

Servidor: w8767ca9.ala.us-east-1.emqxsl.com · porta 8883 (TLS) · usuário RICARDO. Cada comando tem o seu próprio tópico. Publique os comandos sem retain, senão o ESP32 repete o comando toda vez que reconectar.

Como testar rápido: use o app MQTTX (ou o cliente web do painel do EMQX), conecte com o mesmo servidor, usuário e senha, assine casa/# e publique, por exemplo, toggle em casa/cmd/luz_sala. Ou use o modo ao vivo na aba Painel.
Segurança: quem tiver o usuário e a senha do broker consegue acionar a sua casa. Não compartilhe o config.h nem esta página com a senha preenchida. Depois que tudo funcionar, ligue a validação do certificado (MQTT_USE_INSECURE false e o CA do EMQX no config.h).

Instalação

  1. Instale a Arduino IDE e, no Gerenciador de Placas, a placa esp32 (Espressif).
  2. No Gerenciador de Bibliotecas, instale IRremoteESP8266 e PubSubClient (de Nick O'Leary).
  3. Crie uma pasta chamada casa_esp32 e salve nela os três arquivos da aba Códigos: casa_esp32.ino, config.h e webui.h.
  4. Edite o config.h: nome e senha do Wi-Fi (2,4 GHz), API_TOKEN e os nomes dos pontos. Servidor, usuário e senha do MQTT já estão preenchidos.
  5. Selecione a placa ESP32 Dev Module, escolha a porta e clique em Carregar.
  6. Abra o Monitor Serial (115200). Aparece o IP da placa e, em seguida, MQTT conectando... ok.
  7. No celular (mesmo Wi-Fi), abra http://casa.local ou o IP. Digite a senha do API_TOKEN e use "Adicionar à tela inicial".

Dica: no roteador, reserve um IP fixo para o ESP32. Depois da primeira carga, dá para atualizar pelo Wi-Fi (OTA), com a mesma senha.

Configurar os aparelhos

TVs Samsung e LG já vêm prontas em CODES_SAMSUNG e CODES_LG. Se a sua for de outra marca, ou um botão não responder, capture os códigos.

Ares-condicionados: o protocolo padrão é COOLIX, que atende várias marcas, mas pode não ser o seu.

Home theater: os códigos vêm zerados, então os botões só funcionam depois que você capturar os do seu controle.

Capturar códigos do seu controle

  1. Ligue o receptor IR em uma placa ESP32: VCC em 3,3 V, GND e sinal no GPIO 14.
  2. Na Arduino IDE: Arquivo › Exemplos › IRremoteESP8266 › IRrecvDumpV2.
  3. Confira kRecvPin = 14, carregue e abra o Monitor Serial.
  4. Aponte o controle e aperte cada botão. O Monitor mostra o protocolo (ex.: NEC) e o código (ex.: 0x20DF10EF).
  5. Ar-condicionado: o nome do protocolo (ex.: GREE, SAMSUNG_AC) vai em AC_DEVICES no config.h.
  6. TV ou home theater: copie os códigos para uma tabela IrButtons e ajuste o protocolo em IR_DEVICES.

Acesso de fora de casa

Não precisa abrir porta no roteador: o ESP32 conecta no broker MQTT, e você controla de qualquer lugar pela aba Painel (modo ao vivo) ou por um app MQTT, como o MQTTX. O painel local http://casa.local continua acessível só dentro da sua rede.

Códigos do projeto

Salve os três arquivos na mesma pasta casa_esp32. Só o config.h precisa de edição.

// Automação residencial com ESP32
// Controla: relés (luzes/tomadas), TVs, home theater e ares-condicionados (IR)
// Dois jeitos de controlar:
//   1) Painel web local no celular: http://casa.local
//   2) MQTT (EMQX Cloud): um tópico para cada comando, de qualquer lugar
//
// Bibliotecas (Gerenciador de Bibliotecas): IRremoteESP8266 e PubSubClient

#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <WebServer.h>
#include <ESPmDNS.h>
#include <ArduinoOTA.h>
#include <PubSubClient.h>
#include <IRremoteESP8266.h>
#include <IRsend.h>
#include <IRac.h>
#include <time.h>

#include "config.h"
#include "webui.h"

WebServer server(80);
WiFiClientSecure netClient;
PubSubClient mqtt(netClient);

IRsend* irSenders[NUM_IR_OUTPUTS];
IRac*   acs[NUM_AC];
bool    relayOn[NUM_RELAYS];

// Tópicos:
//   comandos (o ESP32 escuta):  casa/cmd/<slug>[/<comando>]
//   estado   (o ESP32 publica): casa/state/<slug>[/<campo>]   (retido)
//   conexão:                    casa/status  = online | offline
#define TOPIC_STATUS MQTT_BASE "/status"
#define TOPIC_CMD    MQTT_BASE "/cmd/"
#define TOPIC_STATE  MQTT_BASE "/state/"

static const char* const MODES_OK[] = {"cool", "heat", "dry", "fan", "auto"};
static const char* const FANS_OK[]  = {"auto", "low", "med", "high"};

// ------------------------------------------------------------------ utilidades
static bool isOn(const String& v) {
  return v == "1" || v.equalsIgnoreCase("on") || v.equalsIgnoreCase("true");
}
static bool oneOf(const String& v, const char* const* list, size_t n) {
  for (size_t i = 0; i < n; i++) if (v == list[i]) return true;
  return false;
}
static void pub(const String& topic, const String& value) {
  if (mqtt.connected()) mqtt.publish(topic.c_str(), value.c_str(), true);  // retido
}

// ------------------------------------------------------------------ relés
static void publishRelay(size_t i) {
  pub(String(TOPIC_STATE) + RELAY_SLUGS[i], relayOn[i] ? "1" : "0");
}
static void setRelay(size_t i, bool on) {
  relayOn[i] = on;
  digitalWrite(RELAY_PINS[i], (on != RELAY_ACTIVE_LOW) ? HIGH : LOW);
  publishRelay(i);
}

// ------------------------------------------------------------------ ar-condicionado
static stdAc::opmode_t parseMode(const String& m) {
  if (m == "heat") return stdAc::opmode_t::kHeat;
  if (m == "dry")  return stdAc::opmode_t::kDry;
  if (m == "fan")  return stdAc::opmode_t::kFan;
  if (m == "auto") return stdAc::opmode_t::kAuto;
  return stdAc::opmode_t::kCool;
}
static const char* modeName(stdAc::opmode_t m) {
  switch (m) {
    case stdAc::opmode_t::kHeat: return "heat";
    case stdAc::opmode_t::kDry:  return "dry";
    case stdAc::opmode_t::kFan:  return "fan";
    case stdAc::opmode_t::kAuto: return "auto";
    default:                     return "cool";
  }
}
static stdAc::fanspeed_t parseFan(const String& f) {
  if (f == "low")  return stdAc::fanspeed_t::kLow;
  if (f == "med")  return stdAc::fanspeed_t::kMedium;
  if (f == "high") return stdAc::fanspeed_t::kHigh;
  return stdAc::fanspeed_t::kAuto;
}
static const char* fanName(stdAc::fanspeed_t f) {
  switch (f) {
    case stdAc::fanspeed_t::kLow:    case stdAc::fanspeed_t::kMin:  return "low";
    case stdAc::fanspeed_t::kMedium: return "med";
    case stdAc::fanspeed_t::kHigh:   case stdAc::fanspeed_t::kMax:  return "high";
    default:                         return "auto";
  }
}

static void publishAc(size_t i) {
  const stdAc::state_t& n = acs[i]->next;
  String base = String(TOPIC_STATE) + AC_DEVICES[i].slug + "/";
  pub(base + "power", n.power ? "1" : "0");
  pub(base + "temp",  String((int)n.degrees));
  pub(base + "mode",  modeName(n.mode));
  pub(base + "fan",   fanName(n.fanspeed));
}

// Altera um campo do ar (sem enviar IR ainda). Retorna false se campo/valor inválido.
static bool acSet(size_t id, const String& field, const String& v) {
  stdAc::state_t& n = acs[id]->next;
  if (field == "power") { n.power = isOn(v); return true; }
  if (field == "temp")  { n.degrees = constrain(v.toInt(), 16, 30); return true; }
  if (field == "mode" && oneOf(v, MODES_OK, 5)) { n.mode = parseMode(v); return true; }
  if (field == "fan"  && oneOf(v, FANS_OK, 4))   { n.fanspeed = parseFan(v); return true; }
  return false;
}
static void acSend(size_t id) {
  acs[id]->sendAc();
  publishAc(id);
}

// ------------------------------------------------------------------ IR (TV / home)
static uint32_t codeFor(const IrButtons* b, const String& cmd) {
  if (cmd == "power")   return b->power;
  if (cmd == "volUp")   return b->volUp;
  if (cmd == "volDown") return b->volDown;
  if (cmd == "mute")    return b->mute;
  if (cmd == "chUp")    return b->chUp;
  if (cmd == "chDown")  return b->chDown;
  if (cmd == "source")  return b->source;
  return 0;
}
// Retorna nullptr se enviou, ou o texto do erro.
static const char* applyIr(size_t dev, const String& cmd) {
  const IrDevice& d = IR_DEVICES[dev];
  uint32_t code = codeFor(d.codes, cmd);
  if (code == 0) return "Botao invalido ou nao configurado em config.h";
  irSenders[d.ir]->send(d.protocol, code, 32);
  return nullptr;
}

// ------------------------------------------------------------------ MQTT
static void publishAll() {
  for (size_t i = 0; i < NUM_RELAYS; i++) publishRelay(i);
  for (size_t i = 0; i < NUM_AC; i++) publishAc(i);
}

// Chega uma mensagem em casa/cmd/<slug>[/<comando>]
static void onMqtt(char* topic, byte* payload, unsigned int len) {
  String t(topic);
  String v;
  v.reserve(len);
  for (unsigned int i = 0; i < len; i++) v += (char)payload[i];
  v.trim();
  Serial.printf("MQTT << %s = %s\n", topic, v.c_str());

  const String prefix(TOPIC_CMD);
  if (!t.startsWith(prefix)) return;
  String rest = t.substring(prefix.length());
  int sl = rest.indexOf('/');
  String slug = (sl < 0) ? rest : rest.substring(0, sl);
  String sub  = (sl < 0) ? ""   : rest.substring(sl + 1);

  // Relé: casa/cmd/luz_sala  -> 1 | 0 | toggle
  for (size_t i = 0; i < NUM_RELAYS; i++) {
    if (slug == RELAY_SLUGS[i] && sub == "") {
      bool on = (v == "toggle") ? !relayOn[i] : isOn(v);
      setRelay(i, on);
      return;
    }
  }
  // TV / home: casa/cmd/tv_sala/power  (qualquer conteúdo)
  for (size_t i = 0; i < NUM_IR_DEVICES; i++) {
    if (slug == IR_DEVICES[i].slug) {
      const char* err = applyIr(i, sub);
      if (err) mqtt.publish(MQTT_BASE "/error", (String(topic) + ": " + err).c_str());
      return;
    }
  }
  // Ar: casa/cmd/ar_sala/power|temp|mode|fan
  for (size_t i = 0; i < NUM_AC; i++) {
    if (slug == AC_DEVICES[i].slug) {
      if (!acSet(i, sub, v)) {
        mqtt.publish(MQTT_BASE "/error", (String(topic) + ": campo ou valor invalido").c_str());
        return;
      }
      if (sub != "power") acs[i]->next.power = true;  // ajustar liga o ar, como no controle
      acSend(i);
      return;
    }
  }
}

static void mqttLoop() {
  if (mqtt.connected()) { mqtt.loop(); return; }
  static uint32_t last = 0;
  if (millis() - last < 5000) return;
  last = millis();
  if (WiFi.status() != WL_CONNECTED) return;

  String id = String("casa-esp32-") + String((uint32_t)ESP.getEfuseMac(), HEX);
  Serial.print("MQTT conectando... ");
  // Último desejo: se a placa cair, o broker publica "offline"
  if (mqtt.connect(id.c_str(), MQTT_USER, MQTT_PASS, TOPIC_STATUS, 1, true, "offline")) {
    Serial.println("ok");
    mqtt.publish(TOPIC_STATUS, "online", true);
    mqtt.subscribe(MQTT_BASE "/cmd/#", 1);
    publishAll();
  } else {
    Serial.printf("falhou (codigo %d)\n", mqtt.state());
  }
}

// ------------------------------------------------------------------ API HTTP (painel local)
static bool authorized() {
  if (server.header("X-Token") == API_TOKEN) return true;
  server.send(401, "text/plain", "Senha invalida");
  return false;
}

static String stateJson() {
  String j = "{\"relays\":[";
  for (size_t i = 0; i < NUM_RELAYS; i++) {
    if (i) j += ',';
    j += "{\"n\":\""; j += RELAY_NAMES[i];
    j += "\",\"on\":"; j += relayOn[i] ? "true" : "false"; j += '}';
  }
  j += "],\"ir\":[";
  for (size_t i = 0; i < NUM_IR_DEVICES; i++) {
    if (i) j += ',';
    j += "{\"n\":\""; j += IR_DEVICES[i].name;
    j += "\",\"ch\":"; j += (IR_DEVICES[i].codes->chUp != 0) ? "true" : "false"; j += '}';
  }
  j += "],\"ac\":[";
  for (size_t i = 0; i < NUM_AC; i++) {
    if (i) j += ',';
    const stdAc::state_t& n = acs[i]->next;
    j += "{\"n\":\""; j += AC_DEVICES[i].name;
    j += "\",\"power\":"; j += n.power ? "true" : "false";
    j += ",\"temp\":"; j += (int)n.degrees;
    j += ",\"mode\":\""; j += modeName(n.mode);
    j += "\",\"fan\":\""; j += fanName(n.fanspeed);
    j += "\"}";
  }
  j += "]}";
  return j;
}

static void sendState() {
  server.send(200, "application/json; charset=utf-8", stateJson());
}

static void handleRelay() {
  if (!authorized()) return;
  int ch = server.arg("ch").toInt();
  if (ch < 0 || ch >= (int)NUM_RELAYS) { server.send(400, "text/plain", "Rele invalido"); return; }
  String st = server.arg("state");
  bool on = (st == "" || st == "toggle") ? !relayOn[ch] : (st == "1");
  setRelay(ch, on);
  sendState();
}

static void handleIr() {
  if (!authorized()) return;
  int dev = server.arg("dev").toInt();
  if (dev < 0 || dev >= (int)NUM_IR_DEVICES) { server.send(400, "text/plain", "Dispositivo invalido"); return; }
  const char* err = applyIr(dev, server.arg("cmd"));
  if (err) { server.send(400, "text/plain", err); return; }
  sendState();
}

static void handleAc() {
  if (!authorized()) return;
  int id = server.arg("id").toInt();
  if (id < 0 || id >= (int)NUM_AC) { server.send(400, "text/plain", "Ar invalido"); return; }
  static const char* const fields[] = {"power", "temp", "mode", "fan"};
  bool changed = false;
  for (const char* f : fields) {
    if (server.hasArg(f) && acSet(id, f, server.arg(f))) changed = true;
  }
  if (changed && !server.hasArg("power")) acs[id]->next.power = true;
  acSend(id);
  sendState();
}

// ------------------------------------------------------------------ setup / loop
static void connectWifi() {
  WiFi.mode(WIFI_STA);
  WiFi.setHostname(HOSTNAME);
  WiFi.setAutoReconnect(true);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  Serial.print("Conectando ao Wi-Fi");
  uint32_t t0 = millis();
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print('.');
    if (millis() - t0 > 30000) { Serial.println("\nFalhou, reiniciando..."); ESP.restart(); }
  }
  Serial.print("\nIP: "); Serial.println(WiFi.localIP());
}

void setup() {
  Serial.begin(115200);

  // Relés: define o nível "desligado" ANTES de virar saída (evita pulso no boot)
  for (size_t i = 0; i < NUM_RELAYS; i++) {
    digitalWrite(RELAY_PINS[i], RELAY_ACTIVE_LOW ? HIGH : LOW);
    pinMode(RELAY_PINS[i], OUTPUT);
    relayOn[i] = false;
  }

  // Saídas IR
  for (size_t i = 0; i < NUM_IR_OUTPUTS; i++) {
    irSenders[i] = new IRsend(IR_PINS[i]);
    irSenders[i]->begin();
  }

  // Ares-condicionados
  for (size_t i = 0; i < NUM_AC; i++) {
    acs[i] = new IRac(IR_PINS[AC_DEVICES[i].ir]);
    stdAc::state_t& n = acs[i]->next;
    n.protocol = AC_DEVICES[i].protocol;
    n.model = -1;
    n.power = false;
    n.mode = stdAc::opmode_t::kCool;
    n.celsius = true;
    n.degrees = 24;
    n.fanspeed = stdAc::fanspeed_t::kAuto;
    n.swingv = stdAc::swingv_t::kOff;
    n.swingh = stdAc::swingh_t::kOff;
  }

  connectWifi();

  // Hora via internet (necessária para validar o certificado TLS)
  configTime(-3 * 3600, 0, "pool.ntp.org", "time.google.com");

  if (MDNS.begin(HOSTNAME)) MDNS.addService("http", "tcp", 80);

  ArduinoOTA.setHostname(HOSTNAME);
  ArduinoOTA.setPassword(API_TOKEN);  // atualização sem cabo exige a mesma senha
  ArduinoOTA.begin();

  // MQTT com TLS
  if (MQTT_USE_INSECURE) netClient.setInsecure();
  else netClient.setCACert(MQTT_CA_CERT);
  mqtt.setServer(MQTT_HOST, MQTT_PORT);
  mqtt.setCallback(onMqtt);
  mqtt.setBufferSize(512);
  mqtt.setKeepAlive(30);

  const char* headerKeys[] = {"X-Token"};
  server.collectHeaders(headerKeys, 1);
  server.on("/", HTTP_GET, []() { server.send_P(200, "text/html; charset=utf-8", INDEX_HTML); });
  server.on("/api/state", HTTP_GET, []() { if (authorized()) sendState(); });
  server.on("/api/relay", HTTP_POST, handleRelay);
  server.on("/api/ir", HTTP_POST, handleIr);
  server.on("/api/ac", HTTP_POST, handleAc);
  server.begin();

  Serial.println("Pronto! Painel local: http://" HOSTNAME ".local");
}

void loop() {
  ArduinoOTA.handle();
  server.handleClient();
  mqttLoop();

  static uint32_t lastCheck = 0;
  if (millis() - lastCheck > 10000) {
    lastCheck = millis();
    if (WiFi.status() != WL_CONNECTED) WiFi.reconnect();
  }
}

Problemas comuns

SintomaO que fazer
casa.local não abreUse o IP do Monitor Serial. Alguns Androids não resolvem .local
Luz liga ao ligar o ESP32Troque RELAY_ACTIVE_LOW entre true e false
Relé não acionaConfira se o módulo está em 5 V (VIN) e se o GND é comum
TV ou ar não respondeAproxime o LED, confira o transistor e capture o código do seu controle
Painel pede senha de novoA senha digitada não bate com API_TOKEN
Ar liga mas ignora temperaturaProtocolo errado em AC_DEVICES
Botão do home theater avisa "não configurado"Capture o código e preencha CODES_HOME
Serial mostra MQTT falhou (codigo -2)Sem internet ou servidor/porta errados. Confira MQTT_HOST e a porta 8883
Serial mostra codigo 4 ou 5Usuário ou senha recusados. Confira MQTT_USER e MQTT_PASS
Não conecta com MQTT_USE_INSECURE falseCole o CA certificate completo do seu deployment no config.h e espere a hora sincronizar
Comando se repete ao reconectarO comando foi publicado com retain. Publique sem retain
Modo ao vivo fica em "aguardando o ESP32"A placa está offline ou o prefixo dos tópicos é diferente do MQTT_BASE
